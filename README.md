🎙️ Text-to-Speech Converter

A simple and interactive Text-to-Speech (TTS) Converter built using HTML, CSS, and JavaScript.
This project allows users to type or paste text into a textbox and listen to it being read aloud using the browser's built-in Speech Synthesis API.


🌐 Live Demo

👉 Live Link- https://harini-honey7.github.io/project-management/

🚀 Features

📝 Easy-to-use Interface – Clean and minimal UI.

🔊 Instant Conversion – Converts text to speech in real-time.

🌍 Multiple Voices & Languages – Supports available voices in the browser.

🎚️ Adjustable Pitch & Rate – Customize the speaking style.

📱 Responsive Design – Works on desktop and mobile browsers.

⚡ No Dependencies – Pure HTML, CSS, and JavaScript.

🛠️ Technologies Used

HTML5 – Structure of the app

CSS3 – Styling and layout

JavaScript (ES6+) – Text-to-speech functionality using SpeechSynthesis API
